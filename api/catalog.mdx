## 覆盖面（coverage）模型

每个端点属于三种覆盖面之一，`capabilities_detail` 中逐条标注：

| coverage | 含义 | 调用体验 |
|---|---|---|
| `market-wide` | 全市场一份数据（如涨跌榜、最新披露流） | 无标的参数，直接调用 |
| `on-demand` | 按标的物化 | 任意标的可查；**首次**查询冷门标的可能 `202`，几秒后重试即命中（见[数据新鲜度](/api/data-freshness)） |
| `working-set` | 限定标的池（derived 域 = 产品内 Dealer 覆盖票池） | 池内标的直接调用；池外返回 `404` |

## 通用参数惯例

- 按标的查询：标的在路径中（`/v1/shorts/data/{ticker}`），大写代码。
- 按合约查询（options 域）：OSI 合约代码在路径中（`/v1/options/contract-daily/{contract}`）。
- 历史/列表类：`from` / `to` / `limit` / `cursor`，语义见[通用约定](/api/conventions)。
- 各端点的完整参数与响应结构：顶部「API Reference」标签页。

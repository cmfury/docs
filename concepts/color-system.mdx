## 柱状图与热力图颜色：方向与强度

先确认产品视图。GEX Dashboard 的柱状图与日内历史热力图用绿色系表示正净 GEX、红色系表示负净 GEX；它们的颜色规则不能套在 Dealer Heatmap 上。

Dealer Heatmap 使用深暗紫、红橙到浅黄的连续色带，按全帧有符号净值的最小值与最大值映射。深紫是数值最小端，浅黄是最大端；这不是绝对值强度，也不是每个到期日单独缩放。全负图里浅黄可以仍为负，全正图里深紫可以仍为正。真实零值落在哪种颜色取决于该帧上下界。

颜色帮助定位候选，判断符号与量级看悬停数字。比较不同时刻、不同标的或不同到期的节点时，不能把同色当成同值。详见[矩阵与色阶读法](/heatmap/reading-the-matrix)。

## 行权价标记颜色：节点角色

以下标记属于 GEX Dashboard。除了绿/红色阶之外，行权价列表中的**文字颜色**和**边框**用来标识该行权价在当前结构中的特殊角色：

| 视觉标记 | 含义 | 出现条件 |
|----------|------|---------|
| **金色文字 + ◆ 菱形** + 左侧金色边框 | King Strike——GEX 绝对值最大的节点 | 所有到期分组 |
| **紫色文字** + 左侧紫色边框 | Gatekeeper——GEX 绝对值第二大的节点 | 所有到期分组 |
| **青色文字** + 右侧青色边框 | Active Call——当日到期合约中 Call 成交最活跃 | 仅 0DTE 和 1DTE |
| **琥珀色文字** + 右侧琥珀色边框 | Active Put——当日到期合约中 Put 成交最活跃 | 仅 0DTE 和 1DTE |
| **白色高亮行** | 当前现货价格所在行 | 始终显示 |
| 普通灰色文字 | 无特殊角色 | 其他行权价 |

<Tip>
一个行权价可以同时拥有左侧边框（结构角色）和右侧边框（成交活跃度）。例如，King 行权价同时也是 Active Call 时，你会看到左侧金色边框 + 右侧青色边框同时出现。
</Tip>

## 如何快速读取整体环境

以下描述只适用于 GEX Dashboard。Dealer Heatmap 要看实际净值，不能数黄色与紫色的面积来判断环境。

- 绿色为主 → 正 GEX 主导，当日震荡偏稳，大波动概率低
- 红色为主 → 负 GEX 主导，当日动量偏强，突破后加速风险高
- 上绿下红或上红下绿的对称分布 → 市场在某一行权价两侧存在明显 GEX 分歧，该价位是结构边界

## 热力图颜色的额外含义

以下为 GEX Dashboard 日内热力图的口径，不是 Dealer Heatmap 的行权价 × 到期日矩阵。

- **0DTE 热力图**：颜色跟踪资金流向（近 5 分钟内成交量驱动的 GEX 变化），反映"钱正在往哪里流"
- **Weekly 热力图**：颜色跟踪持仓结构，反映"钱已经在哪里布局"

## 一个容易犯的错误

<Warning>
GEX Dashboard 历史热力图中，深暗色/高透明度的格子 = 那个时间段没有数据（例如盘前），**不是** GEX 为零。

极浅中性色的格子 = 净 GEX 真正接近零。

两者完全不同，不要混淆。Dealer Heatmap 的深紫格可能是大负值，不能沿用此规则；应以数值标记和悬停确认是否缺数据。
</Warning>

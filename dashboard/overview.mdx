## 这个页面给你什么

GEX Dashboard 是 Nightwatch 的核心。它把所有上市期权合约的持仓数据实时聚合、计算、映射成你能直接读懂的结构图——你不需要看期权链、不需要手动算 Gamma，只需要打开页面，关键节点和市场结构一目了然。

<Note>
新一代 [Heatmap 面板](/heatmap/overview) 已经上线——它以「行权价 × 到期日」矩阵展示做市商定位的全景结构。Dashboard 中 Standard 视图的部分能力将在后续版本中逐步向新面板迁移。
</Note>

## 顶部导航栏

| 元素 | 说明 |
|------|------|
| **标的下拉** | 切换观察标的（SPY、QQQ 等） |
| **0DTE / 1DTE / WEEKLY** | 三个到期分组，每个分组对应不同的持仓时间框架 |
| **LIVE 指示灯** | 绿色脉冲 = 实时更新；灰色 = 连接中断（会自动重连） |
| **MKT OPEN / MKT CLOSED** | 美东时间市场状态 |
| **Standard / Chart** | 切换 Dashboard 视图模式 |
| **GEX / VOL 模块切换** | 切换到 Volatility 面板 |

## 两种视图模式

Dashboard 提供两种视图，通过顶部切换按钮选择：

<CardGroup cols={2}>
  <Card title="Chart 视图（默认）" icon="chart-line">
    K 线图 + PULSE 做市商标记 + Option Buy Volume 柱状图。右侧可展开 Flow 面板查看实时异动。

    适合日内交易者实时跟盘——价格走势、做市商定位和资金流向在同一画面。

    → 详见 [Dealer Chart 与 PULSE](/dashboard/dealer-chart)、[Flow 面板](/dashboard/uw-flow)
  </Card>
  <Card title="Standard 视图" icon="table">
    结构面板 + 历史热力图。以表格和热力图展示 GEX 数值分布和日内演化。

    适合需要精确数值参考或回看日内结构变化的场景。

    → 详见 [结构面板](/dashboard/structure-panel)、[历史热力图](/dashboard/heatmap-panel)
  </Card>
</CardGroup>

## 工作流建议

1. **开盘前**：先看 Weekly GEX 判断本周结构，再切到 1DTE 预判今天的 Gamma 格局
2. **开盘后**：切到 0DTE，找 King Strike 和 Gamma Flip
3. **日内**：实时观察热力图，感知结构节点是否在漂移；用 1DTE 辅助判断隔夜持仓方向

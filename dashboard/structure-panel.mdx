## 这个面板给你什么

结构面板是 Nightwatch 的"当前状态快照"——展示此刻市场在哪些行权价上积聚了最大的 Gamma 压力，每个关键节点在哪里，整体环境是偏稳定还是偏动量。0DTE 数据每 10 秒更新一次，1DTE 和 Weekly 每 30 秒更新一次。

## 顶部统计卡片

### 第一行（所有分组）

| 指标 | 读法 | 交易含义 |
|------|------|---------|
| **King** | 当前最强节点行权价 | 当日最重要的磁吸/阻力价位，是优先级最高的结构参考 |
| **Major Positive** | 正 GEX 方向最强节点 | 当日上方结构核心节点，突破此位多方结构显著改变 |
| **Major Negative** | 负 GEX 方向最强节点 | 当日下方结构核心节点，跌破此位空方结构显著改变 |
| **Total GEX** | 全部行权价 GEX 净合计 | 正值 = 整体稳定偏好；负值 = 整体动量偏好 |

### 第二行（0DTE 和 1DTE 分组）

| 指标 | 读法 | 交易含义 |
|------|------|---------|
| **Call Wall** | Call 持仓最集中行权价 | 上方天然阻力 |
| **Put Wall** | Put 持仓最集中行权价 | 下方天然支撑 |
| **Active Call** | 当日到期合约中 Call 成交最活跃的行权价 | 多方博弈最热点，代表当日买权资金的主战场 |
| **Active Put** | 当日到期合约中 Put 成交最活跃的行权价 | 空方博弈最热点，代表当日卖权资金的主战场 |
| **Max Change 1 Min** | 最近 1 分钟 GEX 变化最大的行权价 | 突破可能正在发生的位置，极短线参考 |
| **Max Change 5 Min** | 最近 5 分钟 GEX 变化最大的行权价 | 比 1 分钟更稳定的热点区域 |

<Note>
**Wall 和 Active 经常指向不同的行权价**——Wall 来自所有到期日的累积持仓，Active 来自当日到期合约的实时成交。两者不一致时，说明存量持仓的结构重心和日内交易者的实际博弈焦点不在同一位置。详细解释参见[关键节点](/concepts/key-nodes)。
</Note>

<Note>
Weekly 分组只展示第一行的持仓结构指标，不包含 Active Call/Put 和 Max Change。
</Note>

## 行权价列表中的特殊标记

| 标记 | 含义 |
|------|------|
| **◆** 金色文字 + 左侧金色边框 | King Strike，当日最重要节点 |
| 紫色文字 + 左侧紫色边框 | Gatekeeper，次强节点（GEX 第二大） |
| 白色高亮行 | 当前现货价格所在位置 |
| `FLIP [价格]`（虚线） | Gamma Flip，正负 GEX 分界线 |
| 青色文字 + 右侧青色边框 | Active Call 行权价（0DTE 和 1DTE） |
| 琥珀色文字 + 右侧琥珀色边框 | Active Put 行权价（0DTE 和 1DTE） |

<Tip>
**边框位置有含义**：左侧边框标识结构角色（King / Gatekeeper），右侧边框标识成交活跃度（Active Call / Active Put）。当一个行权价同时拥有两种角色时，左右边框会同时出现。
</Tip>

## 实战读法

- King 在当前价格**上方**：价格存在向上的磁吸力，做空需要更强的催化剂
- King 在当前价格**下方**：价格存在向下的磁吸力，做多需要更强的催化剂
- 价格在 Flip **上方**：正 GEX 环境，震荡策略占优
- 价格在 Flip **下方**：负 GEX 环境，动量策略占优
- Major Positive 和 Major Negative 之间：当日结构核心区间，价格能否突破这个区间往往决定全天走势

## Copy TV CSV — 导出 GEX 数据到 TradingView

结构面板顶部有一个 **Copy TV CSV** 按钮，点击后将当前所有行权价的 GEX 数据复制到剪贴板，格式为 CSV：

```
strike,put_gex_b,call_gex_b
600,0.012345,-0.006789
599,0.008901,-0.003456
...
```

- `strike`：行权价
- `put_gex_b`：该行权价的 Put GEX（单位：十亿美元）
- `call_gex_b`：该行权价的 Call GEX（单位：十亿美元）

复制后可以粘贴到 TradingView 的自定义指标中使用，把 GEX 节点直接叠加到你的 K 线图上。

f_manage_dynamic(bool show, string full_sess, string plot_sess, color c_col, string name, bool show_history, bool ignore_sweeps, bool show_labels, bool use_prev_only, string txt_size_str, int ln_w, bool show_p, bool alert_on, string tzone, string alert_mode, int offset_val) =>
    bool is_monitoring = not na(time(timeframe.period, full_sess, tzone))
    bool new_session   = is_monitoring and not is_monitoring[1]
    bool session_end   = is_monitoring[1] and not is_monitoring
    bool can_plot      = not na(time(timeframe.period, plot_sess, tzone))

    string lbl_sz = f_get_size(txt_size_str)
    var int current_sess_id = 0
    if new_session
        current_sess_id := time

    var float run_h = na
    var int   run_h_idx = na
    var float run_l = na
    var int   run_l_idx = na

    var DynamicLevel obj_h = na
    var DynamicLevel obj_l = na
    var DynamicLevel prev_obj_h = na
    var DynamicLevel prev_obj_l = na

    if new_session
        if not na(obj_h)
            if not show_history and not na(prev_obj_h)
                line.delete(prev_obj_h.ln)
                label.delete(prev_obj_h.lbl)
            prev_obj_h := obj_h
            if use_prev_only
                line.set_color(prev_obj_h.ln, c_col)
                label.set_textcolor(prev_obj_h.lbl, c_col)
                prev_obj_h.is_swept := false

        if not na(obj_l)
            if not show_history and not na(prev_obj_l)
                line.delete(prev_obj_l.ln)
                label.delete(prev_obj_l.lbl)
            prev_obj_l := obj_l
            if use_prev_only
                line.set_color(prev_obj_l.ln, c_col)
                label.set_textcolor(prev_obj_l.lbl, c_col)
                prev_obj_l.is_swept := false

        if not use_prev_only and not show_history
            if not na(prev_obj_h)
                line.delete(prev_obj_h.ln)
                label.delete(prev_obj_h.lbl)
            if not na(prev_obj_l)
                line.delete(prev_obj_l.ln)
                label.delete(prev_obj_l.lbl)

        run_h     := high
        run_h_idx := bar_index
        run_l     := low
        run_l_idx := bar_index
        obj_h     := na
        obj_l     := na

    else if session_end and use_prev_only
        if not na(prev_obj_h)
            line.set_color(prev_obj_h.ln, na)
            label.set_textcolor(prev_obj_h.lbl, na)
        if not na(prev_obj_l)
            line.set_color(prev_obj_l.ln, na)
            label.set_textcolor(prev_obj_l.lbl, na)

        if not na(obj_h)
            line.set_color(obj_h.ln, c_col)
            label.set_textcolor(obj_h.lbl, c_col)
        if not na(obj_l)
            line.set_color(obj_l.ln, c_col)
            label.set_textcolor(obj_l.lbl, c_col)

    else if is_monitoring
        if high >= run_h
            run_h     := high
            run_h_idx := bar_index
        if low <= run_l
            run_l     := low
            run_l_idx := bar_index

    if show
        int final_offset = 3 + offset_val

        if use_prev_only
            if not na(prev_obj_h) and is_monitoring
                bool crossed = alert_mode == "影线触碰" ? high > prev_obj_h.price : close > prev_obj_h.price
                if crossed and not prev_obj_h.is_swept
                    f_trigger_alert(true, name, "Prev High", prev_obj_h.price, alert_on)

                bool visual_cross = high > prev_obj_h.price
                if not ignore_sweeps and visual_cross
                    prev_obj_h.is_swept := true
                if not prev_obj_h.is_swept
                    line.set_x2(prev_obj_h.ln, bar_index + final_offset)
                    label.set_x(prev_obj_h.lbl, bar_index + final_offset)

            if not na(prev_obj_l) and is_monitoring
                bool crossed = alert_mode == "影线触碰" ? low < prev_obj_l.price : close < prev_obj_l.price
                if crossed and not prev_obj_l.is_swept
                    f_trigger_alert(true, name, "Prev Low", prev_obj_l.price, alert_on)

                bool visual_cross = low < prev_obj_l.price
                if not ignore_sweeps and visual_cross
                    prev_obj_l.is_swept := true
                if not prev_obj_l.is_swept
                    line.set_x2(prev_obj_l.ln, bar_index + final_offset)
                    label.set_x(prev_obj_l.lbl, bar_index + final_offset)

        color draw_col = use_prev_only and is_monitoring ? na : c_col
        color txt_col  = use_prev_only and is_monitoring ? na : c_col

        if na(obj_h) and (can_plot or (is_monitoring and not na(run_h)))
            line l = line.new(run_h_idx, run_h, bar_index, run_h, color=draw_col, width=ln_w)
            string t = f_lbl_text(name, "H", run_h, show_p)
            label lb = label.new(bar_index, run_h, t, textcolor=txt_col, style=label.style_label_left, color=color.new(color.white, 100), size=lbl_sz)
            obj_h := DynamicLevel.new(run_h, run_h_idx, l, lb, false, current_sess_id, name + " H", c_col)
            if not show_labels
                label.set_text(lb, "")

        if not na(obj_h)
            if obj_h.sess_id == current_sess_id
                if is_monitoring
                    if run_h > obj_h.price
                        obj_h.price := run_h
                        obj_h.index := run_h_idx
                        line.set_y1(obj_h.ln, run_h)
                        line.set_y2(obj_h.ln, run_h)
                        line.set_x1(obj_h.ln, run_h_idx)
                        label.set_y(obj_h.lbl, run_h)
                        if show_labels
                            label.set_text(obj_h.lbl, f_lbl_text(name, "H", run_h, show_p))
                    line.set_x2(obj_h.ln, bar_index + final_offset)
                    label.set_x(obj_h.lbl, bar_index + final_offset)
                else
                    bool crossed = alert_mode == "影线触碰" ? high > obj_h.price : close > obj_h.price
                    if crossed and not obj_h.is_swept
                        f_trigger_alert(true, name, "High", obj_h.price, alert_on)

                    bool visual_cross = high > obj_h.price
                    if not ignore_sweeps and visual_cross
                        obj_h.is_swept := true
                    if not obj_h.is_swept
                        line.set_x2(obj_h.ln, bar_index + final_offset)
                        label.set_x(obj_h.lbl, bar_index + final_offset)

            if not use_prev_only or not is_monitoring
                line.set_color(obj_h.ln, c_col)
                label.set_textcolor(obj_h.lbl, c_col)
                label.set_text(obj_h.lbl, f_lbl_text(name, "H", obj_h.price, show_p))
            if use_prev_only and is_monitoring
                line.set_color(obj_h.ln, na)
                label.set_textcolor(obj_h.lbl, na)

        if na(obj_l) and (can_plot or (is_monitoring and not na(run_l)))
            line l = line.new(run_l_idx, run_l, bar_index, run_l, color=draw_col, width=ln_w)
            string t = f_lbl_text(name, "L", run_l, show_p)
            label lb = label.new(bar_index, run_l, t, textcolor=txt_col, style=label.style_label_left, color=color.new(color.white, 100), size=lbl_sz)
            obj_l := DynamicLevel.new(run_l, run_l_idx, l, lb, false, current_sess_id, name + " L", c_col)
            if not show_labels
                label.set_text(lb, "")

        if not na(obj_l)
            if obj_l.sess_id == current_sess_id
                if is_monitoring
                    if run_l < obj_l.price
                        obj_l.price := run_l
                        obj_l.index := run_l_idx
                        line.set_y1(obj_l.ln, run_l)
                        line.set_y2(obj_l.ln, run_l)
                        line.set_x1(obj_l.ln, run_l_idx)
                        label.set_y(obj_l.lbl, run_l)
                        if show_labels
                            label.set_text(obj_l.lbl, f_lbl_text(name, "L", run_l, show_p))
                    line.set_x2(obj_l.ln, bar_index + final_offset)
                    label.set_x(obj_l.lbl, bar_index + final_offset)
                else
                    bool crossed = alert_mode == "影线触碰" ? low < obj_l.price : close < obj_l.price
                    if crossed and not obj_l.is_swept
                        f_trigger_alert(true, name, "Low", obj_l.price, alert_on)

                    bool visual_cross = low < obj_l.price
                    if not ignore_sweeps and visual_cross
                        obj_l.is_swept := true
                    if not obj_l.is_swept
                        line.set_x2(obj_l.ln, bar_index + final_offset)
                        label.set_x(obj_l.lbl, bar_index + final_offset)

            if not use_prev_only or not is_monitoring
                line.set_color(obj_l.ln, c_col)
                label.set_textcolor(obj_l.lbl, c_col)
                label.set_text(obj_l.lbl, f_lbl_text(name, "L", obj_l.price, show_p))
            if use_prev_only and is_monitoring
                line.set_color(obj_l.ln, na)
                label.set_textcolor(obj_l.lbl, na)

    DynamicLevel ret_h = na
    DynamicLevel ret_l = na

    if use_prev_only
        if not na(prev_obj_h) and not prev_obj_h.is_swept
            ret_h := prev_obj_h
            ret_h.name := name + " Prev H"
            ret_h.col := c_col
        if not na(prev_obj_l) and not prev_obj_l.is_swept
            ret_l := prev_obj_l
            ret_l.name := name + " Prev L"
            ret_l.col := c_col
    else
        if not na(obj_h) and not obj_h.is_swept
            ret_h := obj_h
        if not na(obj_l) and not obj_l.is_swept
            ret_l := obj_l

    [ret_h, ret_l]

f_manage_open(bool show, color c_col, bool show_history, bool show_labels, string txt_size_str, int ln_w, bool show_p, string sess_spec, string tzone, int offset_val) =>
    int t = time("D", sess_spec, tzone)
    bool new_day_start = not na(t) and t != t[1]

    var line  l_open = na
    var label lb_open = na
    string lbl_sz = f_get_size(txt_size_str)
    var float day_open_price = na

    if new_day_start
        day_open_price := open
        if not show_history
            line.delete(l_open)
            label.delete(lb_open)

        if show
            l_open := line.new(bar_index, day_open_price, bar_index, day_open_price, color=c_col, width=ln_w)
            string t_lbl = f_lbl_text("Day", "Open", day_open_price, show_p)
            lb_open := label.new(bar_index, day_open_price, t_lbl, textcolor=c_col, style=label.style_label_left, color=color.new(color.white, 100), size=lbl_sz)
            if not show_labels
                label.set_text(lb_open, "")

    int final_offset = 3 + offset_val
    if show and not na(l_open)
        line.set_x2(l_open, bar_index + final_offset)
        label.set_x(lb_open, bar_index + final_offset)
        line.set_color(l_open, c_col)
        label.set_textcolor(lb_open, c_col)
        label.set_text(lb_open, f_lbl_text("Day", "Open", day_open_price, show_p))

    DynamicLevel ret = na
    if show and not na(l_open)
        ret := DynamicLevel.new(day_open_price, bar_index, l_open, lb_open, false, 0, "Day Open", c_col)
    ret

f_manage_pd(bool show, color c_col, bool show_history, bool ignore_sweeps, bool show_labels, string txt_size_str, int ln_w, bool show_p, bool alert_on, string alert_mode, string tzone, int offset_val) =>
    int d = dayofmonth(time, tzone)
    bool new_day = d != d[1]

    var float run_h = high
    var float run_l = low
    var float pdh = na
    var float pdl = na

    if new_day
        pdh := run_h
        pdl := run_l
        run_h := high
        run_l := low
    else
        run_h := math.max(run_h, high)

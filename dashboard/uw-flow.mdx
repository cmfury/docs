## 这个面板给你什么

Flow 面板实时展示当前标的的**异常期权成交流**——大单、扫单、大宗交易，在 K 线图右侧栏以滚动列表实时更新。

它回答的问题很简单：**现在这个标的上，谁在用真金白银表态？**

只展示当日交易时段数据。每切换一次标的，Flow 自动跟随，旧标的数据清空。

---

## 每行字段解读

每一行代表一笔异常成交。从左到右：

| 元素 | 含义 |
|------|------|
| **左侧色条** | 绿色 = CALL，红色 = PUT |
| **时间** | 美东时间 HH:MM:SS |
| **行权价 + C/P** | 例如 "585C" = $585 Call |
| **买 / 卖 / 中** | aggressor 方向。**买** = ask 侧发起（买方主导），**卖** = bid 侧发起（卖方主导），**中** = 在 mid 成交 |
| **类型图标** | 成交方式标记（见下方说明） |
| **权利金** | 该笔成交的总权利金金额（$xxK / $xxM） |
| **张数** | 合约张数 |
| **Ask 占比条** | 绿色比例越高 = 该笔更偏买入发起 |

### 类型图标

| 图标 | 类型 | 含义 |
|------|------|------|
| ⚡ | 扫单（Sweep） | 跨交易所扫货，通常代表急迫的方向性需求 |
| ▣ | 大宗（Block） | 场外协商的大额成交 |
| ⇆ | 多腿（Multileg） | 组合策略成交，如价差、跨式等 |

## 筛选器

点击面板顶部的筛选按钮打开弹窗，可以缩小关注范围：

| 筛选维度 | 选项 |
|----------|------|
| **方向** | CALL / PUT |
| **买卖方向** | 买（ask）/ 卖（bid）/ 中（mid） |
| **类型** | 扫单 / 大宗 / 连续扫（Repeated Hits）/ 多腿 |
| **数量区间** | 最小 / 最大张数 |
| **权利金区间** | 最小 / 最大权利金 |

<Tip>
  修改筛选条件后，点击**"应用"**才会生效。筛选不会打断实时数据流——新成交仍然会按筛选条件过滤后推送。
</Tip>

## 注意事项

<Warning>
  **买/卖只代表 aggressor 方向，不代表开仓或平仓。** 系统无法可靠区分一笔成交是"买入开仓"还是"买入平仓"——你看到的"买"只是说这笔成交发生在 ask 侧，意味着买方更急迫。不要直接将"买"等同于"看涨"。
</Warning>

<Note>
  - Flow 面板**只在 Chart 视图中可见**（Standard 视图没有这个面板）。
  - 切换标的后，Flow 数据跟随切换，旧标的数据**自动清空**。
  - 数据范围为**当日交易时段**，不包含盘前盘后。
</Note>

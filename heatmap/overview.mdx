## 这个面板给你什么

Heatmap 是 Nightwatch 的做市商定位热力图——它把一个标的**未来 90 天内所有真实挂牌的期权合约**上的做市商 Gamma 敞口估计，铺成一张「行权价 × 到期日」的矩阵。

每一行是一个行权价，每一列是一个真实到期日，每个格子的颜色和数值告诉你：在这个位置，做市商的对冲力量有多强、朝哪个方向。

一句话：**这是一张价格的"地形图"**。它不预测价格去哪，但它告诉你——价格如果要动，哪里是墙，哪里是坡，哪里是一马平川。

<Note>
你不需要懂任何期权定价公式就能使用这个面板。所有计算在后端实时完成，你要学的只有一件事：**怎么读这张图**。这套文档会从零开始带你读懂它。
</Note>

## 为什么这张图有意义

期权市场的另一端站着做市商。他们不赌方向，但每卖出一张期权，就必须在股票市场持续买卖标的来对冲风险——这种对冲是**被迫的、机械的、大规模的**。

当大量对冲需求聚集在某个行权价附近时，价格走到那里就会遇到真实的买卖压力：有的位置像磁铁一样把价格吸住，有的位置像加速器一样把价格推得更快。

Heatmap 做的事，就是把这种看不见的力量分布**画出来**。

→ 想理解背后的完整机制，看[做市商对冲机制](/learn/dealer-positioning)

## 面板基本信息

| 项目 | 说明 |
|------|------|
| **入口** | 站内导航中的 Heatmap 页面 |
| **覆盖范围** | 未来约 90 天内的全部真实挂牌到期日 |
| **支持标的** | 以面板内标的选择器为准（当前包括 SPY、QQQ 等） |
| **更新频率** | 交易时段实时更新 |
| **数据口径** | 基于全市场期权数据实时估计的做市商 Gamma 敞口分布 |

<Note>
非交易时段看到的是最后一次快照。热力图结构每天都会随持仓变化重新演化——昨天的图不代表今天的结构。
</Note>

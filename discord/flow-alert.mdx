## 功能定位

Flow Alert 把盘中 SPY 和 SPX 的 0DTE 大单实时推送到 Discord 专用频道。你不需要一直盯着 Flow 面板——打开 Discord，今天的大资金动向一目了然。

只推 **ask 侧**（买入发起方）的大单，过滤掉噪音，聚焦真正有方向意义的成交。

---

## 触发条件

| 标的 | 最低张数 |
|------|---------|
| **SPY** | 1,000 张 |
| **SPX** | 100 张 |

只有达到阈值的 ask 侧成交才会触发推送。bid 侧和小单不推。

---

## 消息格式

每条推送一行，格式如下：

```
🟢 10:32  SPY 585C  买⚡  $125.50K  1,200张  avg $1.05
```

### 各字段含义

| 字段 | 说明 |
|------|------|
| 🟢 / 🔴 | 🟢 = Call，🔴 = Put |
| 时间 | 美东时间 HH:MM |
| 标的 + 行权价 | 如 `SPY 585C` = SPY 585 Call |
| 买 + 执行类型 | ⚡ = Sweep（扫单，跨交易所扫货）；▣ = Floor（大宗 / 场内交易） |
| 权利金 | 总金额，格式 `$xxK`（千）或 `$xxM`（百万） |
| 张数 | 成交合约数，格式 `x张` 或 `xK张` |
| avg | 平均成交价格 |

### 执行类型说明

- **Sweep（⚡）**：扫单——买方同时扫多个交易所的挂单来快速成交，通常代表急迫的方向性需求
- **Floor（▣）**：大宗或场内交易——规模大但不一定代表急迫的方向判断，可能是机构的大额对冲单

---

## 推送节奏

每 **15 秒** 批量推送一次，避免触发 Discord 消息限速。同一批次内的多笔大单会合并在一条消息中。

---

## 怎么解读

<Warning>
Ask 侧大单代表的是"买入发起方"，不是"一定看涨"。大量 Call 买入可能是开仓做多，也可能是平掉空头仓位。Flow Alert 告诉你大资金在行动，具体含义需要结合市场上下文判断。
</Warning>

### 实用读法

- **密集的 🟢 Call 买入** → 大资金偏多头方向行动，配合 PULSE 图上金色线（Dealer GEX 正值区）判断是否有结构支撑
- **密集的 🔴 Put 买入** → 大资金偏空头方向行动，关注当前价格是否在 Gamma Flip 下方（动量放大区）
- **Sweep（⚡）连续出现** → 买方急迫，方向信号更强
- **单笔超大额 Floor（▣）** → 机构大单，关注但不急于跟随——可能是对冲而非方向性交易

### 配合 Dashboard 使用

Flow Alert 告诉你"谁在行动"，Dashboard 告诉你"价格在哪里会有反应"。两者结合：当大单方向和 GEX 节点位置一致时，信号可靠性更高。

---

## 注意事项

- 只推 ask 侧——你看到的是买入发起方的行为，不是全部大单
- 0DTE 专属——只推当天到期的合约，不覆盖其他到期日
- 非交易时段无推送——美股开盘（9:30 AM ET）到收盘（4:00 PM ET）期间才有数据
- Flow Alert 是信息输入，不是交易信号——大单可以是开仓、平仓、对冲，单靠一条推送无法判断
